# Bharat Vamsi — Motion Reel (Motion Canvas)

A ~21s motion-graphics reel built with Motion Canvas for the promotion
business case. Uses only verified numbers from the deck.

## Sequence
1. Title — "The operating engine behind a $275M retail media network"
2. Data supply chain — Meijer 1P data -> 5 platforms (DV360, TTD, GAM, Meta, Pinterest) -> Advertiser ROAS
3. Verified metrics count-up — $275M, +134% ROAS, +107% CVR, >98% DIF, 968 campaigns
4. Growth — $75M -> $275M (3.7x), retained, no added headcount
5. Outro — Account Manager -> Senior Manager

## Run / edit
    npm install --legacy-peer-deps
    npm run serve         # editor at http://localhost:9000

Rendered output is committed at ../bharat-vamsi-motion-reel.mp4
